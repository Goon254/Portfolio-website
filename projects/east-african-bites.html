East African Bites

Full-stack food ordering platform for a cottage food business — chapatis, mandazis, and East African snacks with pickup and delivery.

Next.js TypeScript Supabase Twilio Zustand Tailwind
Visit Site →

Why I Built This

I love baking — especially chapatis (flatbread) and mandazis (East African snacks). After graduation, job hunting as an international student has been tough. I got creative and started this small business to help pay bills while sharing the food I love with my community.

Project Overview

Core Features

  • Full-stack e-commerce with pickup and delivery options
  • Zone-based delivery fees and daily capacity limits
  • Multi-step checkout with Zod validation and React Hook Form
  • Twilio SMS for order confirmations, status updates, and cancellations
  • Admin dashboard for order management and financial tracking
  • Cart system with Zustand and localStorage persistence
  • Phone verification for secure order lookup

Technical Architecture

  • Next.js 16 with Server Actions and React 19
  • Supabase (PostgreSQL) for orders, delivery zones, and capacity logic
  • RPC functions for order numbering and capacity checks
  • Twilio integration for SMS notifications
  • Zustand for state management, Framer Motion for animations
  • Tailwind CSS for responsive, mobile-first UI
