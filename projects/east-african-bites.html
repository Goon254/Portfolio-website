🍞 git log --origin-story
I love baking — especially chapatis (flatbread) and mandazis (East African donuts). After graduation, job hunting as an international student meant visa complexities and waiting periods. Instead of waiting, I got creative.

This platform started as a solution to a real problem: "How do I pay bills while sharing the food I love?" It evolved into a production-grade e-commerce system handling real orders, real customers, and real delivery logistics. // Sometimes the best side projects are the ones that pay rent

Database Schema

➜ ~/supabase/schema.sql # PostgreSQL
CREATE TABLE orders (
id UUID PRIMARY KEY DEFAULT gen_random_uuid()
order_number SERIAL UNIQUE
customer_phone VARCHAR NOT NULL
items JSONB NOT NULL
delivery_zone VARCHAR REFERENCES zones(name)
status ENUM DEFAULT 'pending'
created_at TIMESTAMP DEFAULT NOW()
);
CREATE TABLE delivery_zones (
name VARCHAR PRIMARY KEY
fee DECIMAL NOT NULL
max_orders_per_day INTEGER DEFAULT 10
);
