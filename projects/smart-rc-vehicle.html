Embedded systems

Smart RC Vehicle

An Arduino Nano vehicle with a 100 Hz PID control loop, Bluetooth control over an HC-05 module, ultrasonic obstacle avoidance and live serial telemetry.

Role
Hardware, firmware, tuning
Hardware
Arduino Nano (ATmega328P), L298N motor driver, HC-05 Bluetooth, HC-SR04 ultrasonic, 7.4 V Li-Po
Firmware
Embedded C++, PID library, SoftwareSerial
Status
Complete

Control

The control loop runs at 100 Hz and computes a discrete PID output for motor PWM: proportional gain 2.5, integral 0.1 with windup limited to ±50, derivative 0.8 with noise filtering. A ±5 count deadband on the encoder stops jitter at rest. Tuning was done on the bench with the serial monitor streaming setpoint, input and output every cycle.

Behaviour

  • Manual mode. Direction and speed commands arrive over Bluetooth at 9600 baud and map to PWM duty on the H-bridge.
  • Autonomous mode. The ultrasonic sensor scans 2 to 400 cm; an obstacle inside the threshold triggers a stop and a 90° turn sequence before the PID loop re-stabilises heading.
  • Diagnostics. RGB status LEDs and a low-battery warning from the voltage divider.

The compiled sketch used about 60% of program memory and 43% of RAM, which left room for the telemetry buffer without touching the control loop timing.
