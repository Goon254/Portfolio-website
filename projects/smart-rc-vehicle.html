PID Controller Implementation
u(t) = Kpe(t) + Ki∫e(t)dt + Kd(de/dt)
// Discrete implementation for embedded systems
output = (Kp * error) + (Ki * integral) + (Kd * (error - last_error))
P
Proportional
Immediate response to error
I
Integral
Eliminates steady-state drift
D
Derivative
Dampens oscillations
Parameter Value Unit Description
Kp 2.5 - Proportional gain (aggressive correction)
Ki 0.1 - Integral gain (windup limited to ±50)
Kd 0.8 - Derivative gain (noise filtered)
Sample Rate 100 Hz Control loop frequency (10ms period)
PWM Resolution 8-bit - 0-255 duty cycle (Timer1)
Deadband ±5 counts Encoder tick threshold to prevent jitter

1  double PID::compute(double setpoint, double input) {
2    double error = setpoint - input;
3    double dInput = input - lastInput;
4    
5    // Proportional term
6    double P = kp * error;
7    
8    // Integral with windup guard
9    integral += ki * error;
10    if (integral > 50) integral = 50;
11    else if (integral < -50) integral = -50;
12    
13    // Derivative on measurement (not error) to avoid derivative kick
14    double D = -kd * dInput;
15    
16    // Compute output
17    double output = P + integral + D;
18    
19    // Constrain to PWM range
20    if (output > 255) output = 255;
21    else if (output < 0) output = 0;
22    
23    lastInput = input;
24    return output;
25  }
