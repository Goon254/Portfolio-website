The system

Daytrader started as a pair of execution bots and grew into a four-layer platform. A swarm of worker bots watches the chain through Helius: a pump.fun launch watcher, a token lifecycle tracker, a creator wallet profiler and a whale indexer that reconstructs per-wallet, per-token profit and loss from raw transactions. Each writes to its own Postgres tables.

ML nodes read only that observer data and score wallets on traits like good launcher, rug, smart money and longevity. A governor sets risk thresholds from the closed-trade history. Execution bots sit at the top with a Rust trade engine compiled as a Node addon for the latency-sensitive path, plus a backtesting framework over historical candles ingested from Binance and Solana DEX sources.

The rule that made it maintainable: reads cross layers, writes never do, and bot outputs never feed model training.

Tripwire, the product

The same intelligence turned out to be more valuable as data than as trades, so I productised it as Tripwire: early-warning intelligence for Solana token launches.

  • Rug radar. Creator history, mint and freeze authority, holder concentration and sybil-funded launches.
  • Dump early-warning. Fingerprints the developer and insider dump before it lands, using pre-entry bundle buyers and live holder concentration.
  • Smart-money feed. Vetted wallets with forensic per-token PnL.
  • Bundle and farmer map. Coordinated launches and wash clusters.

Delivered over REST, WebSocket and webhooks as JSON with a threat class and confidence score. Signup is a self-custodial Solana Pay checkout that issues an API key, with a free Recon tier and paid Operator and Syndicate tiers.

Engineering notes

Hardening took as much work as the signals. Public rate limits, a least-privilege database role, secrets separated per process, tiered and masked rosters with watermarking to resist bulk extraction, and an access log. The API runs containerised behind Traefik with automatic TLS, the bots under PM2, and Redis handles hot state.

Risk lives inside the trading side too: a hard real-balance drawdown halt, profit-protect trailing on realised PnL, conviction-based position sizing and a roster feedback loop that prunes wallets proven negative.
