Machine learning

Fruit Classifier

A convolutional neural network that classifies images into 15 fruit categories, with a data augmentation pipeline and a full evaluation report.

Role
Model design, training, evaluation
Stack
Python, TensorFlow 2, Keras, NumPy, OpenCV
Data
15 classes · ~10k training images · 2k test images
Result
94% test accuracy

Approach

Images are resized to 224×224 and augmented with flips, rotations and brightness shifts in a preprocessing pipeline. The network stacks two convolutional blocks (32 and 64 filters, 3×3, ReLU) with batch normalisation, max pooling and dropout, then a 128-unit dense layer and a 15-way softmax.

Evaluation

94.2%accuracy
92.8%precision
93.5%recall

Evaluated on a held-out set of 2,000 images with a confusion matrix per class. Most remaining errors were between visually similar pairs, which the augmentation pass narrowed but did not remove.

Structure

  • cnn_model.py — model definition.
  • preprocess.py — augmentation and dataset loading.
  • evaluate.py — metrics, confusion matrix and plots.
  • train.ipynb — training runs and checkpoints.
