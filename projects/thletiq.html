ThletIQ

AI-powered fitness platform that generates personalized workout programs — free, structured gym plans without subscriptions.

Next.js React TypeScript PostgreSQL Prisma Clerk Vercel
Visit thletiq.com →

Why I Built This

I was tired of big fitness apps charging users just to get a structured gym plan. When my friend Allan asked me to make him a workout plan, I decided to build something that would enable many people to have structure in the gym without paying a penny.

Project Overview

Core Features

  • AI-powered program generation from user onboarding (experience level, goals, equipment)
  • 200+ exercises with equipment substitution logic and movement-pattern coverage
  • Personalized workout plans adapted to fitness goals and weekly availability
  • End-to-end workout tracking: session logging, set/rep/weight, RPE, personal records
  • Progress dashboards with volume trends, muscle distribution, and streak tracking
  • Secure authentication and real-time workout logging across dashboard and history views

Technical Architecture

  • Next.js 16, React 19, TypeScript — full-stack app deployed on Vercel
  • PostgreSQL (Neon) with Prisma ORM for workout sessions, progress, and streaks
  • RESTful API for program generation, progress tracking, and personal records
  • Clerk authentication and Zustand state management
  • Recharts for data visualization (volume trends, muscle distribution)
  • Tailwind CSS for responsive UI
