💪 git log --origin-story
I was tired of big fitness apps charging users just to get a structured gym plan. When my friend Allan asked me to make him a workout plan, I decided to build something bigger — a platform that would enable many people to have structure in the gym without paying a penny.

The result: An AI-powered system that generates personalized programs based on experience, goals, and available equipment. No subscriptions. No paywalls. Just gains.

Generation Algorithm

Collect experience level, fitness goals, available equipment, weekly schedule

Movement Pattern Analysis
Map goals to exercise categories: Push/Pull/Legs, Upper/Lower, Full Body

API Architecture

POST /api/program/generate
Generate personalized workout program from user profile data
POST /api/workout/log
Log completed workout session with sets, reps, weight, and RPE
GET /api/progress/volume
Retrieve volume trends for dashboard visualization (Recharts)
GET /api/exercises
Fetch exercise database with filtering by equipment and muscle group
GET /api/pr/records
Get personal records and progression history

model Program {
id String @id @default(uuid())
name String
split SplitType
weeks Int
workouts Workout[]
user User @relation(fields: [userId], references: [id])
}
